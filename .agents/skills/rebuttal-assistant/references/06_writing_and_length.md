# 06 — Writing and Length Control

## 1. Two-stage drafting

### Stage A: Chinese logic draft

先完整写出：
- 对问题的理解。
- 作者立场。
- 关键证据。
- 论证过程。
- 必要的局限说明。
- 修改动作。
- 总结结论。

此阶段不急于控制字符数。

### Stage B: English rebuttal

- 保持中文论证逻辑不变。
- 使用准确、自然、易懂的学术英语。
- 避免过度复杂词汇和长句。
- 直接表达数字、原因和实验结论。
- 保留必要的限定条件，避免过度断言。

## 2. Compression order

字符超限时，按以下顺序压缩：
1. 删除重复感谢和重复背景。
2. 合并重复的上下文。
3. 删除不影响论证的修饰语。
4. 缩短句式。
5. 将多个审稿人的共性问题合并到 Common Response（仅当规则和结构允许）。
6. 调整表格或格式（仅当会议允许）。

不要优先删除：
- 直接答案。
- 关键实验数字。
- 证据与结论之间的逻辑。
- 影响结论范围的必要限定。
- 对审稿人具体问题的回应。

## 3. Readability

- 避免过多括号、分号。
- 避免一个句子承载过多层次。
- 少用空泛词汇，如 “significant”, “novel”, “substantial”，除非有具体依据。
- 避免模板化重复。
- 术语与论文正文保持一致。
- 统一缩写、变量名、数据集名称和指标名称。

## 4. Tone

推荐：
- “Thank you for raising this concern.”
- “We clarify that...”
- “The results in Table X show...”
- “This comparison isolates...”
- “We acknowledge that the original presentation could be clearer.”
- “This limitation affects [scope], but does not alter [bounded claim], as supported by...”

谨慎使用：
- “We completely agree...”
- “This proves...”
- “Clearly...”
- “Obviously...”
- “We will...”
- “Our method is significantly better...”

以上表达并非绝对禁止，关键是语义、证据和承诺必须匹配。

## 5. Character counting

- 先确认会议官方定义的字符/字数限制。
- 核实空格、换行、Markdown 标记、LaTeX、引用、表格是否计入。
- 不根据第三方工具的计数方式推断官方计数。
- 最终以投稿系统或官方说明为准。

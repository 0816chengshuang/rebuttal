# 09 — Rebuttal Quality Checklist

## A. Strategy

- [ ] 是否识别了审稿人真正关注的问题？
- [ ] 是否区分了 Contribution、Validity、Evidence、Presentation？
- [ ] 是否区分了误解、言外之意、实质性质疑和局限？
- [ ] 是否优先处理影响录用判断的核心问题？
- [ ] 是否重点关注低分审稿人的关键顾虑？

## B. Directness and evidence

- [ ] 是否直接回答了问题？
- [ ] 是否明确给出数量、原因或实验结论？
- [ ] 是否提供了真实的论文证据？
- [ ] Section、Equation、Figure、Table、Appendix 编号是否准确？
- [ ] 数字和实验结果是否可追溯？
- [ ] 是否避免让审稿人自行寻找答案？

## C. Author stance and tone

- [ ] 是否保持礼貌、诚恳、专业？
- [ ] 是否避免对抗性或讽刺性表达？
- [ ] 是否避免无条件接受未经证明的负面判断？
- [ ] 是否避免不必要的自我否定？
- [ ] 是否如实承认局限并界定影响范围？

## D. Response quality

- [ ] 是否给出证据而非空谈？
- [ ] 是否解释证据最终说明什么？
- [ ] 是否将误解转化为清晰的澄清？
- [ ] 是否提出具体、可执行的修改动作？
- [ ] 是否指出准确修改位置（如适用）？
- [ ] 是否避免空泛的“We will improve the writing”？

## E. Promise and policy

- [ ] 所有未来承诺是否真实可执行？
- [ ] 是否将已完成工作正确描述为已完成？
- [ ] 是否核对当前会议是否允许相应承诺或修改？
- [ ] 是否避免承诺无法兑现的实验或 Camera Ready 修改？

## F. Language and length

- [ ] 英文是否自然、准确、易读？
- [ ] 是否避免过多括号、分号和复杂句？
- [ ] 中英文论证是否一致？
- [ ] 是否在不损害逻辑的情况下压缩？
- [ ] 是否按官方规则核对字符/字数？
- [ ] Common Response 是否确实减少重复且没有漏答？

## G. Final formatting

- [ ] Reviewer ID 是否正确？
- [ ] Q/A 编号是否完整？
- [ ] Markdown、LaTeX、表格是否正确渲染？
- [ ] 是否在投稿系统中完成最终检查？


## H. Submission format and portal compliance

- [ ] 是否核对了正确年份/届次、Track、投稿类型和评审阶段？
- [ ] 是否优先使用当届官方来源，并记录链接和适用范围？
- [ ] 是否明确区分当届官方模板、官方说明、往届材料、作者范例和第三方模板？
- [ ] 如果没有找到官方模板，是否如实说明而没有虚构？
- [ ] 是否确认实际系统字段布局，而不是套用通用 Q/A 格式？
- [ ] Common Response、Reviewer-specific response 和 confidential AC/Editor note 是否放入正确字段？
- [ ] 期刊是否满足 point-by-point response、修改位置和配套稿件要求？
- [ ] 字符/字数是否按每个实际字段分别核算，并注明计数口径？
- [ ] 登录后才能确认的规则是否明确标记为待作者核对？

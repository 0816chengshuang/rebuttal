# 10 — Submission Format Research

## Purpose

在分析和撰写 Rebuttal 之前，确认目标会议、期刊、出版社、学会或机构是否公开提供正式模板、回复规范或系统字段说明。最终产出必须适配真实投稿入口；通用 Q/A 模板只是备用结构。

## 1. Identify the exact target

确认 Venue / journal / publisher / institution、Year / edition、Track 或 article type、投稿类型，以及当前阶段（初审 rebuttal、revision response、appeal 等）。相同会议不同年份、Track 或评审阶段可能有不同规则。

## 2. Search source hierarchy

1. **当前届官方来源**：当届官网 Author Guidelines / Rebuttal Instructions、FAQ、CFP、官方公告、投稿系统页面和官方模板。
2. **官方组织方/出版机构来源**：主办学会、会议组织方、出版社或期刊编辑部发布的正式说明。
3. **往届官方材料**：往届正式说明，必须标记届次，不能推定本届仍适用。
4. **公开作者范例**：公开 rebuttal 或 response letter，只作为写法参考。
5. **第三方经验材料**：博客、教程、个人模板，只作为经验参考。

## 3. Search queries

- `[venue] [year] rebuttal instructions`
- `[venue] [year] author response guidelines`
- `[venue] rebuttal template`
- `[venue] author response character limit`
- `[venue] OpenReview author response`
- `[journal] response to reviewers guidelines`
- `[publisher] point-by-point response letter template`
- `[institution/association] peer review response template`

必要时分别搜索官方会议网站、投稿平台帮助页面、学会/出版社域名和往届归档页面。

## 4. What must be verified

| 维度 | 核查内容 |
|---|---|
| Official template | 是否有官方 Word / LaTeX / Markdown / PDF 模板 |
| Response structure | 是否要求逐位 Reviewer 回复、Common Response 或 point-by-point |
| Portal fields | 单一文本框、Reviewer 分栏、Common + individual、AC / Editor confidential note |
| Length | 字符/字数限制、每位 Reviewer 或全文限制、计数方式 |
| Formatting | Markdown、LaTeX、表格、图片、链接、附件是否允许 |
| Anonymity | 是否匿名，是否禁止身份或机构信息 |
| Evidence | 是否允许新增实验、引用、补充材料或外链 |
| Revision promises | 是否允许承诺 Camera Ready / revised manuscript 修改 |
| Journal-specific files | 是否需要 response letter、tracked-changes manuscript、clean manuscript、cover letter |
| Deadline and workflow | 截止时间、提交入口、是否允许更新或再次提交 |

## 5. Official template vs. examples

必须明确区分：
- **Official template**：主办方、出版社、期刊编辑部或投稿系统明确发布的模板。
- **Official instructions without a template**：没有可下载模板，但有官方格式或字段要求。
- **Historical official template**：往届正式模板，不能保证本届适用。
- **Public author example**：作者公开的实际回复样例，不代表官方要求。
- **Third-party template**：个人或第三方提供的通用模板。

如果没有检索到公开官方模板，正确表述是：“在已检索的当届官方来源中，未找到公开的统一 Rebuttal 模板；目前应以官方回复规则和投稿系统实际字段为准。”不要为了交付模板而虚构官方模板。

## 6. Submission Format Brief

正式起草前，向作者交付简明调研摘要：

| 项目 | 结果 |
|---|---|
| Venue / year / track | [目标会议/期刊、届次、Track] |
| Official template | [找到/未找到/只有系统字段] |
| Official structure | [官方要求的回复结构] |
| Submission fields | [实际系统字段布局] |
| Length limit | [限制和计数口径] |
| Formatting | [Markdown/LaTeX/表格/图片/链接/附件] |
| Anonymity | [匿名及保密要求] |
| Evidence and promises | [补实验、外链、Camera Ready 承诺的规则] |
| Sources | [链接、来源机构、发布日期、适用届次] |
| Unverified | [需要用户登录系统确认的项目] |

每条关键规则都应有官方来源支撑。对未核实项目明确标记，不得猜测。

## 7. Convert research into a portal-ready deliverable

- **One combined response field**：输出完整回复，按官方要求组织 Common Response 和 Reviewer-specific sections。
- **Separate reviewer fields**：每位 Reviewer 单独输出可直接粘贴的回复。
- **Common + reviewer-specific fields**：共性回复与逐位回复分别输出。
- **Confidential AC / Editor field**：单独起草给 AC / Editor 的保密说明，不得混入公开回复。
- **Journal response letter**：按期刊要求组织正式 point-by-point response letter，并明确 Editor comments、Reviewer comments、manuscript changes 和配套文件要求。

## 8. Final compliance gate

- [ ] 使用正确年份/届次和 Track 的规则。
- [ ] 没有把第三方模板说成官方模板。
- [ ] 输出字段与真实投稿系统一致。
- [ ] Reviewer 顺序和 ID 正确。
- [ ] 字符/字数符合官方限制。
- [ ] 格式、链接、附件、匿名要求合规。
- [ ] 未来修改承诺符合官方政策且作者能够兑现。
- [ ] 若系统登录后才显示关键规则，已请作者提供截图或字段信息核对。
